En este proyecto desarrollé un conversor de temperaturas utilizando HTML, Servlets y Java. Primero creé un formulario llamado temperaturas.html, donde el usuario puede ingresar una temperatura y seleccionar el tipo de conversión que desea realizar. Cuando el usuario envía el formulario, los datos son enviados al TemperaturaServlet mediante el método POST.
En el Servlet utilizo request.getParameter() para obtener la temperatura y el tipo de conversión seleccionada. Luego creo un objeto de la clase ConversorTemperatura, que es la encargada de realizar los cálculos. Esta clase contiene un método llamado convertir() que recibe los datos y devuelve el resultado correspondiente según la conversión elegida.
Finalmente, el Servlet muestra en el navegador la temperatura ingresada, el tipo de conversión realizada y el resultado obtenido. De esta forma se integran HTML para la interfaz, el Servlet para procesar la solicitud y una clase Java para la lógica de negocio
